# Target images

Photos of the competition target markers (concentric rings with digits 1/2/3),
taken by the project author.

- License: MIT (same as the rest of this repository), unless otherwise noted.
- The marker pattern itself is provided by the competition organizers; the
  photos are used here only to illustrate the detection pipeline.
- Files: `target-ring-1.jpg`, `target-ring-2.jpg`, `target-ring-3.jpg`.
  Each image was resized to at most 900 px on its longest edge and re-encoded
  as JPEG to keep the repository small.
